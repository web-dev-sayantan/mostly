# Archive is terminal; there are no pause, rest, or skip states

The product is a journal, not a flexible habit tracker: an expected day without a session is a miss, and a gap in logging produces visible misses rather than a neutral period. Removable pause/rest/skip states were rejected because they turn the record into something the user can edit around, and every "temporary stop" is a pause by another name. Archive ends a goal permanently: the archive day still counts, expectations stop the next logical day, history stays read-only from the next day, and there is no unarchive. To resume, create a new goal.

**Consequences:** vacations and illness appear as misses and reset streaks. Archived goals are excluded from current cards/streaks/consistency but remain in historical aggregates for the dates they were active.
