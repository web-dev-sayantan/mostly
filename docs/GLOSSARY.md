# Mostly — Product

The shared language for the personal daily-ledger product: goals, sessions, expectations, and the visual record.

## Language

**Goal**:
An ongoing practice the user wants to keep doing.
_Avoid_: Habit, task, resolution

**Cadence**:
How often a goal is expected: daily, specific weekdays, or N times per week.
_Avoid_: Schedule, frequency

**Expectation**:
A goal × a logical day on which the goal is expected.
_Avoid_: Due date, occurrence

**Logical day**:
The user's local date, with a configurable rollover (default 4:00 AM).
_Avoid_: Calendar day, wall-clock day

**Session**:
A done record for one goal on one logical day, with optional minutes, note, and mood.
_Avoid_: Check-in, entry, log

**Close the day**:
The daily ritual of reviewing Today and marking what was done.
_Avoid_: Check-in, daily review

**Miss**:
An expected day with no session after rollover. A miss is derived, not stored.
_Avoid_: Failure, skipped day

**Extra**:
A session on a day a daily/weekday goal was not expected. It counts as a session and minutes, but not toward consistency or streaks.
_Avoid_: Bonus, off-day check-in

**Archive**:
A terminal end to a goal. The archive day still counts; expectations stop after it, and history is read-only from the next day.
_Avoid_: Pause, retire, deactivate

**Streak**:
Consecutive expected units done: days for daily/weekday goals, weeks met for weekly-target goals.
_Avoid_: Run, chain

**Streak era**:
A period with the same cadence unit. Changing between daily/weekday and weekly target starts a new era and resets the current streak.
_Avoid_: Streak period

**Consistency**:
Done expected units divided by expected units.
_Avoid_: Completion rate, score

**Progress**:
The visual record of the daily ledger: numbers, heatmaps, strips, and goal cards. It shows the record; it does not tell the user what it means.
_Avoid_: Insights, dashboard, report
